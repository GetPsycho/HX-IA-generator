Quand Eric demande de justifier un choix (pédale, effet, structure du morceau, etc.), toujours inclure les liens URL pour chaque information avancée.

**Why:** L'utilisateur veut pouvoir vérifier lui-même les sources, pas juste lire une affirmation.

**How to apply:** Après chaque justification de choix de preset (pédales, ampli, effets par section), lister les URLs sources avec le contenu correspondant, même si la réponse est courte.

Pour déterminer l'accordage d'un morceau, utiliser **Ultimate Guitar** comme source de référence prioritaire (tabs vérifiées par la communauté, souvent annotées avec le tuning).

**Why:** Plus fiable que les sources générales sur le guitariste ; les tabs UG précisent souvent explicitement le tuning en en-tête.

**How to apply:** Lors de la recherche étape 1 (spécificités du morceau), chercher sur ultimate-guitar.com pour confirmer l'accordage, notamment `"song title" site:ultimate-guitar.com tuning`.

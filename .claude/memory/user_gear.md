Fiche complète dans le workspace : `docs/gear/eric_gear.md`

**Guitare :** Fender Stratocaster US
- Chevalet : DiMarzio Super Distortion (très haute sortie) — **usage principal** (riffs, rhythm)
- Milieu : single-coil Strat d'origine — funk, positions mixtes
- Manche : single-coil Strat d'origine — solos

**Ampli :** Mesa Boogie Single Rectifier 50W — **son clair exclusivement**
**Cab :** Mesa Boogie 2×12
**Connexion :** HX Effects → entrée guitare du Mesa (pas 4CM)

**Wah :** Cry Baby MC404 CAE — externe, avant le HX Effects, pas dans les presets

**Points clés :**
- Super Distortion chevalet = haute sortie → pousse les gains plus fort que les single-coils des guitaristes référence (ne pas compenser, ça donne une sonorité propre à Eric)
- Mesa clean = articulation tight, légèrement brillant → surveiller les Tone élevés
- Micro manche (solos) = faible sortie → KinkyBoost de solo encore plus justifié
- Pas de 4CM → tous les effets passent par le préampli du Mesa

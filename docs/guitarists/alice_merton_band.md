# Guitariste live — Alice Merton

Pas de guitariste nommé documenté publiquement (le groupe live d'Alice Merton inclut
un guitariste allemand, un batteur français et un claviériste, mais sans fiche
gear détaillée trouvée). La version studio de "No Roots" est une production
électro-pop : le riff signature emblématique est une guitare jouée avec un
octaveur (-1 octave) pour sonner comme une basse — ce n'est pas la partie
qu'Eric reproduit (cf. fiche morceau).

## Approche live du groupe d'Eric
Le bassiste joue le riff signature. Eric le double à la guitare, à la même
hauteur (pas d'octave-down), avec un son OD à grain/épaisseur — choix arrangement
propre au groupe d'Eric plutôt que reproduction du gear studio original.

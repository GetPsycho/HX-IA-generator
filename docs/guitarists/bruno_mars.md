## Style
Reggae-rock / pop-rock influence new wave et funk. Mars cite explicitement
The Police comme influence principale ("You try to write a Police song!").
Le "skank" reggae des guitares (coups d'archet courts, staccato, sur le
contretemps) vient de cette influence. Son clean avec **chorus leger
confirme par analyse audio** (rate 0.6 Hz, depth 0.45, confiance forte) —
coherent avec l'influence Andy Summers malgre des sources web sceptiques
sur ce point precis. Saturation tres faible (0.18-0.20) sur la quasi-totalite
du morceau.

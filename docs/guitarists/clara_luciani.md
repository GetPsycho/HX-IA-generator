# Sage (Ambroise Willaume) — guitariste de Clara Luciani

Membre du groupe **Revolver** (trio français : Ambroise Willaume, Christophe Musset, Jérémie Arcache).
Collabore avec Clara Luciani depuis 2014 (production, composition, guitariste live).

- Wikipedia Revolver : https://fr.wikipedia.org/wiki/Revolver_(groupe_fran%C3%A7ais)

## Inspiration sonore : Nile Rodgers

Pour les morceaux **Nue** et **Le Reste**, le son de Sage s'inspire de **Nile Rodgers** :
- Fender Stratocaster clean et brillante
- Compression forte (MXR Dyna Comp) = son "snappy" et compressé caractéristique
- Technique de "chucking" (muting rythmique serré)
- Pas de distorsion — ton funk/pop propre et articulé
- Reverb légère pour l'espace

## Note pour les presets
La compression (Red Squeeze) devrait être le bloc central de ces presets,
pas le Kinky Boost. Le son Nile Rodgers vient avant tout de la Dyna Comp
sur un signal clean brillant.

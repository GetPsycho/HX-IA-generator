# Craig Ross — Lenny Kravitz Band

## Rôle
Guitariste principal de Lenny Kravitz depuis 1991 (tous albums et tournées).
Rencontré dans un billard à Hollywood via Kathy Valentine (The Go-Go's).

## Chaîne de signal — AYGGMW (studio 1993)

```
Gibson Les Paul Goldtop 1953
  → Gibson Skylark (saturé à fond)
  → Tape flanging (ingénieur Henry Hirsch, technique two-tape-machine)
```

## Notes pour les presets

- **AYGGMW riff** : OCD LPHP=False always-on (simulation Gibson Skylark). Flanger Mix discret (0.28).
- **AYGGMW bridge** : même OCD, flanger plus prononcé (Mix 0.48 via params override).
- **AYGGMW solo** : même OCD + KinkyBoost (delta micro manche vs chevalet Super Distortion d'Eric).
- Pas de wah documentée sur ce titre.
- Le flanger studio (tape) est irréproductible exactement — le Gray Flanger en est une approximation acceptable.

## Style de jeu

Influences : Freddie King, Albert King, Jimi Hendrix, Jimmy Page, Chuck Berry, Cream-era Clapton.
Jeu bluesy et improvisé, solos construits sur pentatonique mineure/majeure alternées.
Solo de AYGGMW = une seule prise, du début à la fin, non édité.

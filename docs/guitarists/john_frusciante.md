## Ampli — Marshall Major 200W (1978)

Ampli principal de l'ère Stadium Arcadium.

| Paramètre | Réglage |
|---|---|
| Presence | 6 |
| Bass | 10 (plein boost) |
| Mid | 6–7 |
| Treble | 4 (la Strat apporte les aigus) |
| Volume Bright Channel | 4 |
| Volume Normal Channel | 7 |
| Technique | Les deux canaux bridgés simultanément (patch leads) |

Microphonie studio : SM57 en proximitė + Royer R-121 à ~4m (room mic).

## Chaîne de signal — Dani California (live)

```
Stratocaster 1954 (neck pickup, sections clean)
  → Moog MF-101 Low-Pass Filter (verse : envelope follower)
  → Boss DS-2 Turbo Distortion (chorus / solo)
  → Ibanez WH-10 Wah (solo)
  → Marshall Major 200W (canaux bridgés, Presence 6, Bass 10, Mid 7, Tre 4)
```

Note studio : les effets de verse ont été générés post-production avec le modular Doepfer A-100, puis reproduits live avec le MF-101.

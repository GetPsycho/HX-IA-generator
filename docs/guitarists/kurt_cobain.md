# Kurt Cobain — Nirvana

## Groupe
- Nirvana — 1987-1994

## Guitares principales

| Guitare | Détail |
|---|---|
| **Fender Mustang 1969** (Lake Placid Blue) | **Principale sur Nevermind.** Achetée chez Voltage Guitars pendant les sessions. Micros single-coil stock à l'époque de l'enregistrement. Guitare préférée de Cobain. |
| **Fender Jaguar 1965** (sunburst) | Achetée dans le Recycler LA 1991. Modifiée : **DiMarzio PAF (manche) + DiMarzio Super Distortion (chevalet)**, bridge remplacé par un Gibson Tune-O-Matic. Utilisée en overdub + tournée. |
| Fender Stratocaster (gaucher) | Guitare de scène ponctuelle |

**Note :** La Jaguar '65 avait un DiMarzio Super Distortion au chevalet — même micro que la guitare d'Eric (en manche). Réaction différente aux pédales à prendre en compte selon la position de micro utilisée.

## Amplis (Nevermind, 1991)

| Ampli | Rôle |
|---|---|
| **Mesa Boogie Studio Preamp + Crown Power Base 2** | Cœur du son distordu, couplets/riffs |
| **Fender Bassman** | **Refrains + Lithium spécifiquement** — son plus sombre et plus épais avec le Big Muff |
| Vox AC30 | Overdubs clean, parties strummées |

**Micro d'enregistrement Lithium :** Neumann U87 sur l'ampli guitare (réservé habituellement aux basses fréquences) — choix de Butch Vig pour accentuer les graves du Big Muff.

**Accordage Lithium :** 1 ton plus bas que standard sur l'enregistrement original
— simulé via PolyPitch (Interval=-2) plutôt qu'un retune physique.

## Pédales (ère Nevermind, 1991)

| Pédale | Rôle |
|---|---|
| **Boss DS-1 Distortion** | Distorsion principale Bleach/Nevermind. Level max, Tone 11h-13h, Distortion max (ou réduit en studio). |
| **EHX Big Muff Pi** | **Lithium spécifiquement** (et autres titres). Son plus épais/fuzzy que le DS-1. |
| **EHX Small Clone** | Chorus analogique sur les parties clean. Cobain en avait 5 exemplaires. Rate 12h, Depth haute. |
| ProCo RAT | "Territorial Pissings" uniquement (signal splitté DI). Pas sur Lithium. |

**Pédales In Utero (1993) — pas Nevermind :**
Tech 21 SansAmp, EHX PolyChorus, EchoFlanger.

**MTV Unplugged in New York (1993) — The Man Who Sold the World (Bowie cover) :**
Martin D-18E acoustique-électrique. Malgré le format "Unplugged", Cobain garde
un Boss DS-2 (Digital Distortion) branché en subtil sous l'acoustique sur
l'intro et le solo — ce n'est pas du 100% acoustique pur. Verse en revanche
purement acoustique (son folk, sans DS-2 — confirmé à l'écoute). Pas de
Small Clone audible sur ce titre précis. Accordage demi-ton plus bas
(Eb standard), tonalité réelle La (A). Pat Smear (2e guitare Unplugged)
joue une ligne de basse mobile au chorus — partie non reproduite si
guitariste unique.

## Sons par titre

| Titre | Son principal |
|---|---|
| **Lithium** | Verse quasi-clean + Small Clone / Chorus : Big Muff Pi → Fender Bassman |
| Smells Like Teen Spirit | DS-1 max → Mesa Boogie / Small Clone sur solo |
| Come As You Are | DS-1 modéré + Small Clone (son "watery" signature) |
| In Bloom | DS-1 + Small Clone chorus |
| Polly | Acoustique (Stella H912 cheap) |
| Territorial Pissings | RAT splitté DI + ampli |

## Notes pour les presets

- **Lithium :** `HD2_DistRamsHead` (Big Muff) + `HD2_Chorus70sChorus` (Small Clone approx.) — Tone bas (0.45) pour le caractère sombre/Bassman. Contraste clean/distordu **volontairement non compensé** (philosophie quiet/loud Pixies).
- **DS-1 style :** `HD2_DistDeezOneMod` (DS-1 Keeley modded) ou `HD2_DistVerminDist` (RAT) pour les autres titres Nirvana si nécessaire.
- Small Clone ≈ `HD2_Chorus70sChorus` avec ChorusIntensity 0.40-0.50, Rate 0.35, Mix 0.40. Pas de vibrato marqué.
- Accordage standard (E) sur Nevermind.
- **The Man Who Sold the World :** `L6SPB_AcousGtrSim` + `HD2_DistDeezOneMod`
  (DS-2, subtil — actif Intro/Solo, absent du Verse). Pas de Small Clone
  (non audible sur ce titre). Accordage demi-ton bas simulé via
  `L6SPB_PolyPitch` (Interval=-1, AutoEQ=1.0) — pattern identique a Toxicity
  (Drop D -> Drop C via PolyPitch), ici standard -> Eb standard.

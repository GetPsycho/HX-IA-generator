## Ampli — Mesa Boogie Dual Rectifier Head

Ampli principal de l'ère Make Yourself. Utilisé en configuration clean pour Drive.

| Paramètre | Réglage (Drive — canal clean) |
|---|---|
| Gain | ~1h (très bas, canal clean) |
| Bass | 12h |
| Mid | 12h (~750 Hz, warmth et articulation) |
| Treble | 12h |
| Mode | Clean / Modern channel |
| Tubes de puissance | 6L6 |
| Cabinet | 2x Mesa Boogie 2x12, Celestion 30 |

Réglages alternatifs style Fender Twin (pour répliquer le son de Drive) :
Gain 3 / Bass 5 / Mid 4 / Treble 6 / Reverb 3.

## Chaîne de signal — Drive (live)

```
PRS McCarty Archtop II (neck pickup)
  → Boss CS-3 Compression Sustainer
  → Boss PH-2 Super Phaser (rate très lent sur l'intro)
  → Boss CE-2 Chorus (intro et refrain)
  → Boss RV-3 Reverb/Delay (reverb ambiance)
  → Mesa Boogie Dual Rectifier (canal clean)
```

Technique de l'intro : arpège joué avec le volume guitare roulé à 0, puis augmenté progressivement pendant que le delay/reverb gonfle = effet de swell.

| Titre | Section | Son | Pédales actives | Notes |
|---|---|---|---|---|
| **Drive** | Intro | Clean + phaser très lent + chorus + reverb large | PH-2 (rate lent), CE-2, RV-3 | Arpèges atmosphériques en Em, swell volume |

| **Drive** | Refrain | Clean + phaser + chorus | PH-2, CE-2 | Ouverture du son, CE-2 ajoute du large |

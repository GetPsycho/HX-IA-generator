# Mike Einziger — Incubus

## Guitares principales (ère Make Yourself, 1999)

| Guitare | Micros | Notes |
|---|---|---|
| **PRS McCarty Archtop II** (1998-99) | Humbuckers passifs McCarty | Guitare principale Make Yourself |
| PRS Custom 24 | Humbuckers | Utilisée en alternance |

Drive : **guitare acoustique** pour les sections Intro/Verse/Chorus. Guitare électrique (PRS McCarty, micro manche) pour le solo.

---

## Ampli — Mesa Boogie Dual Rectifier Head

Ampli principal de l'ère Make Yourself. Utilisé en configuration clean pour Drive.

| Paramètre | Réglage (Drive — canal clean) |
|---|---|
| Gain | ~1h (très bas, canal clean) |
| Bass | 12h |
| Mid | 12h (~750 Hz, warmth et articulation) |
| Treble | 12h |
| Mode | Clean / Modern channel |
| Tubes de puissance | 6L6 |
| Cabinet | 2x Mesa Boogie 2x12, Celestion 30 |

| Pédale | Usage |
|---|---|

| Boss CS-3 Compression Sustainer | Contrôle dynamique |
| Boss RV-3 Reverb/Delay | Reverb et delay ambiance |

| ProCo RAT | Crunch léger ponctuel (autres titres) |

---

## Chaîne de signal — Drive (solo électrique)

```
PRS McCarty Archtop II (neck pickup)
  → H&K Tube Rotosphere MkII (SLOW — Leslie simulator)
  → Boss PH-2 Super Phaser
  → Overdrive léger germanium-style
  → Delay sparse
  → Boss RV-3 Reverb
  → Mesa Boogie Dual Rectifier (canal clean)
```

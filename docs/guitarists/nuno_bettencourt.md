# Nuno Bettencourt — Extreme

## Groupe
- Extreme — 1985-présent (ère Pornograffitti : 1990)

## Guitare principale (ère Pornograffitti, 1990)

| Guitare | Détail |
|---|---|
| **Washburn N4** | Chevalet : Bill Lawrence L500-XL (humbucker haute sortie, "razor-edged", transitoires rapides). Manche : Seymour Duncan '59. Vibrato Floyd Rose. Manche huilé/non verni. |

## Chaîne signal (Pornograffitti, 1990)

```
Guitare → Pro Co RAT → ADA MP-1 → Furman EQ → Macintosh (ampli à lampes) → Marshall 4x12 Greenback
```

| Élément | Rôle / réglages |
|---|---|
| **Pro Co RAT** | Toujours actif — rôle de filtre/compression plus que distorsion principale ("compression disguised as distortion"). Distortion ~8-8.5/10, Filter ~13h (1 o'clock), Volume unité/+1dB selon les sources (valeurs cadran à prendre avec prudence — le rôle fonctionnel décrit est plus fiable que le chiffre exact). |
| **ADA MP-1** | Préampli rack, dual 12AX7. Preset 45 utilisé sur l'album. Gain saturé mais articulé (pas un haut-gain scoopé moderne). |
| **Furman PQ-3 EQ** | Creux mid sculpté ~800Hz — tenue funk-metal tight, évite le boueux. |
| **Macintosh** | Ampli hi-fi à lampes utilisé comme étage de puissance (clean headroom). |
| **Marshall 4x12** | Haut-parleurs Greenback. |

**Live (tournée Pornograffitti)** : ADA MC-1 (foot controller) pour piloter le rack. Le Randall NB King 100 (signature ultérieure) reproduit cette chaîne RAT+ADA MP-1+Marshall dans un seul ampli.

## Technique caractéristique

- **Tapping/hammer-on rapide** : base du jeu (riffs et solos), exécuté avec un mute main droite percutant.
- **Trick de "démultiplication" au delay** (intro "He-Man Woman Hater" / "Flight of the Wounded Bumblebee") : peu de notes jouées en tapping, delay synchronisé (Time≈240ms, Feedback≈0 = une seule répétition nette, Mix élevé) ajoute une répétition par note jouée → illusion d'un débit de notes beaucoup plus rapide. Même famille de trick que le delay d'Eddie Van Halen sur "Cathedral".
- **Solo** : legato rapide, unisson bends, double-stop bends, dive bombs au whammy bar (E Mixolydian principalement, excursions pentatonique mineure/mineur naturel).

## Notes pour les presets

- **Pas de modèle HX dédié pour l'ADA MP-1** (préampli rack, pas un ampli "modélisable" classique côté HX Effects). Simulé par une pédale haute-gain articulée (`HD2_DistCompulsiveDrive`, gain plus poussé que le pattern "grunge bien poussé" — voir `docs/pedal_guides/od_dist_fuzz.md`).
- **RAT** → `HD2_DistRatatouilleDist` (LM308 NPN, le plus fidèle au RAT d'époque 1990).
- Le trick de delay de l'intro nécessite son propre snapshot dédié (pas le même son que le Riff principal).

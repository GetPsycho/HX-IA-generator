# Sage (Ambroise Willaume)

Musicien français multi-instrumentiste (guitare, piano, basse, synthés).
Co-fondateur du groupe **Revolver** (Paris, 2006), guitariste et producteur de **Clara Luciani** depuis 2014.
Présent sur les albums *Sainte-Victoire* (2018) et *Cœur* (2021).

- Wikipedia : https://fr.wikipedia.org/wiki/Sage_(musicien)
- Wikipedia Revolver : https://fr.wikipedia.org/wiki/Revolver_(groupe_fran%C3%A7ais)

## Style de jeu — inspiration Nile Rodgers
Le son de Sage sur les morceaux de Clara Luciani (*Nue*, *Le Reste*) s'inspire de **Nile Rodgers** :
- Strat clean et brillante, micros simple-bobinage
- **Compression forte** (MXR Dyna Comp) = attack snappy, sustain compressé
- Technique de "chucking" : accords étouffés rythmiques serrés
- Pas de distorsion — ton funk/pop propre et articulé
- Reverb légère pour l'espace ambiant

## Preset HX Effects

**Fichier :** `output/Californication - Red Hot Chili Peppers.hlx`

**Chaîne :**
```
Gate > CompulsiveDrive > Chorus70s > Reverb > KinkyBoost
  0         1                2           3         4
```

| Snap | Nom | Son |
|---|---|---|
| 0 | Arpege | Clean + CE-1 chorus (Mix=0.30) + Reverb |
| 1 | Chorus | Idem Arpege (même son pour le refrain) |
| 2 | Solo | OCD (Gain=0.45, LPHP=True, Level=0.70) + CE-1 + Reverb + KWB |
| 3 | Clean | Accordage / attente |

**Particularités :**
- OCD togglé uniquement sur Solo (Verse/Chorus sont clean, pas de canal saturé permanent)
- LPHP=True sur OCD : simule le punch britannique du Marshall JTM-45 (Plexi)
- CE-1 Chorus (Mix=0.30) permanent : reproduit en mono l'effet du split stéréo studio (Showman + JTM-45 splittés par CE-1)
- KinkyBoost actif uniquement sur Solo (compensation volume OCD, règle calibration)
- Reverb modérée (Mix=0.16) : pas d'esprit "shoegaze", juste de l'espace

```

  0         1               2            3          4
```

| Snap | Nom | Son |
|---|---|---|
| 0 | Riff | OCD (JCM 2000 DSL sim) + Reverb + KinkyBoost |
| 1 | Chorus | OCD + DD-3 delay + Reverb + KinkyBoost |
| 2 | Solo | OCD Gain=0.78 + DD-3 + Reverb + KinkyBoost |
| 3 | Clean | Accordage / attente |

**Particularités :**
- OCD always-on : simule le Marshall JCM 2000 DSL "gain low, volume full" (saturation power amp)
- KinkyBoost : compensation volume vs référence clean
- Gear studio corrigé : Gibson SG Standard + JCM 2000 DSL (pas Manson + Diezel VH4)

## Preset HX Effects

**Fichier :** `output/No One Knows - QOTSA.hlx`

**Chaîne :**
```
Gate > StuporOD > 10BandEQ > Reverb > KinkyBoost
  0       1          2          3         4
```

| Snap | Nom | Son |
|---|---|---|
| 0 | Principal | SD-1 (Drive=0.18, Tone=0.88, Level=0.70) + EQ mid-boost + Reverb + KWB |
| 1 | Solo | SD-1 (Drive=0.32, Level=0.80) + EQ + Reverb + KWB |
| 2 | Clean | Accordage / attente |
| 3 | Clean | Accordage / attente |

**Particularités :**
- SD-1 réglage Josh Homme : Level/Tone max, Drive minimal = clean boost mid-heavy (pas distorsion)
- EQ 10-Band : +3 dB à 500 Hz, +4 dB à 1 kHz, +2 dB à 2 kHz — signature mid-hump Josh Homme
- Reverb très basse (Mix=0.08) : l'original studio n'a pas de reverb
- KinkyBoost : règle calibration projet (compensation volume)
- Eric utilise la Lag Roxanne en C standard — pas besoin de PolyPitch
